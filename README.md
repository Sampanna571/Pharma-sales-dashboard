# 📊 Pharmaceutical Sales Analytics Dashboard

## Overview
This project analyzes pharmaceutical sales data using Python for exploratory data analysis (EDA) and Power BI to create an interactive dashboard.

## Objectives
- Analyze sales trends and performance
- Identify top-performing products
- Build an interactive dashboard for business insights

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Power BI

## Repository Contents
## Repository Contents

- [pharma_sales_dashboard.pbix](./pharma_sales_dashboard.pbix) – Interactive Power BI dashboard
- [pharma_sales_data.csv](./pharma_sales_data.csv) – Dataset used for analysis
